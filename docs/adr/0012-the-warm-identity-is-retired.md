# The warm identity is retired for the Voltage token system

TinyOrder shipped "The Hand-Lettered Shopfront" — oxblood on cream, Lora signage over a warm cream→taupe surface ladder, soft 12–20px geometry, 1.5px clay hairlines. Its `DESIGN.md` §6 named the alternative and rejected it in as many words: no cold blue/grey panels, no generic SaaS dashboard, and never a cool grey neutral (`#EEE`, `#F5F5F5`, slate) — The Warm-Floor Rule. We are adopting the Voltage UI Kit's token system, which is cool zinc neutrals, sharp 2–12px geometry, hairline borders and one Latin family, keeping oxblood `#7A1028` as the single accent. Voltage is the thing the old §6 rejected. That rejection was a real position and it is being overridden deliberately, not overlooked: this ADR exists so nobody later reads the reversal as drift.

Four consequences worth stating plainly. **(1)** The token *names* lie for one PR. Rather than edit 896 call sites across 68 components, the reskin gave Voltage values to the warm names — `--color-cream` currently resolves to `#FAFAFA` — and a follow-up rename removes the aliases with no visual change, gated on an empty computed-style diff. `tokens.css` carries a header saying so. **(2)** The dark-theme block ships **unverified**. No toggle, no persistence, no dark QA pass ran; the values are a starting point, not tested output, and the first person to switch dark mode on owns checking them. **(3)** `--ink-400` (Voltage's own `--color-text-subtle`) fails AA as body text on `--ink-50` at ~2.46:1. It is borders and decorative icons only — precisely the constraint the retired `clay-muted` carried, and `tokens.test.ts` asserts it stays below the text threshold so nobody promotes it. **(4)** The bilingual pairing collapses from two faces to one: with no Latin serif there is nothing for Noto Serif SC to match, so Chinese headings and body both set in Noto Sans SC.

Two further consequences surfaced in review and are recorded here rather than left to be rediscovered. **(5)** Voltage's type *scale* (`--fs-*` / `--lh-*` / `--tr-*` / `--fw-*` and the `.t-display-xl … .t-mono-sm` classes) was **not** ported as CSS. 896 call sites already size type with Tailwind utilities, so a parallel `.t-*` system would have been dead code from the first commit; `DESIGN.md` §3 documents the scale as prose instead, and adding the classes later is additive and needs no migration. **(6)** The shadcn bridge under `.dark` originally kept stock shadcn's neutral oklch greys, which silently won over the semantic dark map — `--primary` resolved to a light grey rather than the brand accent, so nothing wired for dark reached a shadcn component. It now mirrors the `:root` bridge. It is still untested, like the rest of dark mode.

Two of Voltage's own values did not survive the contrast gate and were changed rather than accepted: its `--success-500 #10B981` carries white text at 2.54:1, replaced with emerald-600 `#059669`; and its `-400` step is the dark-theme accent, so it had to be a light rose (`#D4708A`) rather than the old `oxblood-light #8B2030`, which lands near 2.2:1 on `#09090B`.
